# 文化祭ブロックチェーン 操作説明書

ここから先、人の手で微調整していく際のリファレンスです。
「動かし方」「どこを触れば何が変わるか」「詰まったときの対処」をまとめています。

---

## 1. 前提

- 本番: **Ubuntu**
- 動作確認: **Arch**(諸事情によりこちらで先にテスト)
- どちらのOSでも手順は共通です(下記参照)。

---

## 2. インストール手順(Ubuntu / Arch 共通)

```bash
cd 文化祭ブロックチェーン

# 仮想環境を作る(システムのPythonを汚さないため)
python3 -m venv venv
source venv/bin/activate

# pipが見つからない場合は先に ensurepip を実行
python -m ensurepip --upgrade

# 依存パッケージのインストール
python -m pip install -r requirements.txt
```

`requirements.txt` の中身:

```
Flask>=3.0
pycryptodome>=3.20
requests>=2.31
Pillow>=10.0
```

### インストールでよくあるつまずき

| 症状 | 原因 | 対処 |
|---|---|---|
| `zsh: correct 'pip' to '_pip'?` | `pip`という実行コマンドがPATHに無い(venv内でも起きうる) | `pip`の代わりに `python -m pip` を使う |
| `error: externally-managed-environment` | システムのpipに直接installしようとした | venvを作って`source venv/bin/activate`してからinstallする |
| `ModuleNotFoundError: No module named 'flask'` 等 | venvが有効化されていない | プロンプト先頭に`(venv)`が出ているか確認。出ていなければ`source venv/bin/activate` |
| pipインストールが極端に遅い/固まる | ビルドが走っている(まれ) | 少し待つ。頻発する場合はネットワークを確認 |

## 3. 起動方法

```bash
source venv/bin/activate   # まだの場合
python app.py
```

起動すると以下のような案内がターミナルに出ます。

```
============================================================
[起動] ノード名=node1 / ポート=5000
[このPCで開く場合]      http://localhost:5000
[お客さんのスマホから]   http://192.168.x.x:5000
[QRコードで開きたい場合] http://192.168.x.x:5000/qr にPCのブラウザでアクセス
  ※ スマホがこのPCと同じWi-Fi(同じネットワーク)に
    つながっている必要があります。
[管理画面パスワード]     sensei (環境変数 ADMIN_PASSWORD で変更可)
============================================================
```

### 環境変数一覧(起動時に指定できる設定)

| 環境変数 | デフォルト値 | 説明 |
|---|---|---|
| `NODE_NAME` | `node1` | このノードの名前。SQLiteファイル名(`ノードデータ/<NODE_NAME>.db`)にも使われる |
| `PORT` | `5000` | 待ち受けるポート番号 |
| `ADMIN_PASSWORD` | `sensei` | `/admin` 画面に入るためのパスワード |
| `DEBUG` | `false` | `true`にするとFlaskのデバッグモードで起動(開発時のみ推奨。本番では`false`のまま) |

指定例:

```bash
NODE_NAME=node2 PORT=5001 ADMIN_PASSWORD=himitsu123 python app.py
```

## 4. スマホからのアクセス

1. スマホをサーバーPCと**同じWi-Fi**に接続する。
2. PCのブラウザで `http://localhost:5000/qr` を開き、QRコードを表示する(スクリーン投影 or 印刷)。
3. スマホのカメラでQRコードを読み取ると、そのままトップページが開く。
4. URLを手入力したい場合は、起動時にターミナルへ表示される
   `http://192.168.x.x:5000` の形式のURLを使う。

アクセスできない場合は `/qr` 画面下部にトラブルシューティングが表示されます
(Wi-Fi接続確認・モバイル通信オフ推奨・会場Wi-Fiの端末間通信制限・ファイアウォール確認)。

## 5. よく調整したくなるポイント(ファイル・場所つき)

| 調整したいこと | ファイル | 場所 |
|---|---|---|
| 採掘の難易度(速さ) | `ブロックチェーン/採掘.py` | `DEFAULT_DIFFICULTY = 4`(数字を下げると採掘が速くなる。1〜2で一瞬、5以上で数秒〜) |
| 採掘報酬のコイン数 | `ブロックチェーン/採掘.py` | `MINING_REWARD = 10` |
| 管理画面パスワード | 起動時の環境変数、または `状態.py` | `ADMIN_PASSWORD = os.environ.get("ADMIN_PASSWORD", "sensei")` のデフォルト値を直接書き換えてもよい |
| ポート番号 | 起動時の環境変数 `PORT` | 例: `PORT=8080 python app.py` |
| 配色・デザイン | `static/css/style.css` | 先頭の `:root { ... }` にあるCSS変数(`--bg`, `--amber`, `--teal`, `--red` など)を変更 |
| トップページの文言・説明文 | `templates/index.html` など各テンプレート | Jinja2の`{% block content %}`内のHTML文を直接編集 |
| ナビゲーションの項目 | `templates/base.html` | `<nav class="nav">` 内の`<a>`タグを追加・削除 |
| 各画面のロジック(送金条件など) | `画面/送金画面.py` 等 | Flask Blueprintの各ルート関数内 |

## 7. 複数ノードでの同期・フォーク展示(応用)

別々の端末(または同じPCで別ポート)でノードを2つ以上起動できます。

```bash
# 端末1
NODE_NAME=node1 PORT=5000 python app.py

# 端末2(別ターミナル、または別PC)
NODE_NAME=node2 PORT=5001 python app.py
```

それぞれの `/nodes` 画面で相手のURL(例: `http://192.168.1.10:5001`)を登録し、
「全ノードと同期する」ボタンを押すと、より長いチェーンに切り替わる様子を確認できます。

## 8. 実行時トラブルシューティング

| エラー・症状 | 原因 | 対処 |
|---|---|---|
| `Address already in use` | 指定ポートが既に使われている | `PORT=5001 python app.py` のように別ポートで起動、または既存プロセスを`kill` |
| スマホからアクセスできない | 同じWi-Fiに繋がっていない/会場Wi-Fiが端末間通信を禁止している/ファイアウォール | Wi-Fi設定確認、`sudo ufw allow <PORT>/tcp`(Ubuntu)、モバイル通信を一時的にオフ |
| 採掘に成功しない/画面が固まる | 難易度が高すぎる、または端末のCPUが遅い | `ブロックチェーン/採掘.py` の `DEFAULT_DIFFICULTY` を下げる |
| 送金しても残高が反映されない | まだ「未承認取引」の段階で、誰も採掘していない | `/mine` で誰かが採掘するとブロックに取り込まれ反映される |
| `/admin` に入れない | パスワードが違う | 起動時に指定した`ADMIN_PASSWORD`(未指定なら`sensei`)を確認 |
| チェーンが「改ざんが検出されました」のまま戻らない | 改ざん実験を行った状態が残っている | `/admin` の「全て初期化」でリセット |
